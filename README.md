# Poker IQ 🃏

משחק אימון שמלמד לקבל את ההחלטה הנכונה בכל יד פוקר: פולד, צ׳ק, קול או רייז.
בלי כסף אמיתי ובלי הימורים. זה משחק לימודי.

## מה יש במשחק
- **מסע:** 7 עולמות × 3 שלבים, כוכבים ו-10 רמות. מתחילים מ"כולם ויתרו, נכנסים או לא?" ומגיעים עד 3-בט, צ׳ק-רייז ושעון.
- **8 סוגי סיטואציות** בכל 6 העמדות בשולחן (UTG, HJ, CO, BTN, SB, BB): פתיחה, מול העלאה, ביג בליינד מול לימפים, מול 3-בט, סי-בט, פעולה ראשונה בלי מיקום, מול הימור, ומול צ׳ק-רייז. הסיטואציות מגיעות בפרה-פלופ, פלופ, טרן וריבר.
- **הסבר במילים פשוטות אחרי כל החלטה:** מה קרה ביד, למה הפעולה הנכונה נכונה, ואיפה הייתה הטעות. אפשר ללחוץ על כל מושג (לימפ, אאוטים, מיקום…) ולקבל הסבר. המספרים המדויקים נמצאים בחלק "למתקדמים".
- **מילון** עם יותר מ-45 מושגים.
- **אתגר יומי:** אותן 10 ידיים לכולם, רצף ימים, ושיתוף התוצאה בוואטסאפ.
- **ראש בראש בזמן אמת:** יוצרים חדר, שולחים קישור בוואטסאפ, והחבר נכנס מהדפדפן בלי להתקין כלום.
- **דירוג:** לפי ניקוד כולל, לפי האתגר היומי ולפי ניצחונות.

## איך המאמן מחליט
1. **אקוויטי:** סימולציית מונטה קרלו של אלפי ידיים. היריבים מחזיקים טווח ידיים מציאותי: מי שהעלה מעמדה מוקדמת חזק יותר, ומי שמהמר אחרי הפלופ צריך לפגוע בשולחן.
2. **סיכויי קופה:** כמה צריך לנצח כדי שקריאה תשתלם.
3. **מיקום:** מי שפועל ראשון מממש פחות מהיד שלו.
4. **ספי העלאה** שיורדים ככל שיש יותר יריבים. כשההחלטה על הגבול, שתי תשובות מקבלות ניקוד.

זה מודל לימודי, לא סולבר. הוא לא מתחשב בגודל ערימות או בסגנון של יריב מסוים.

## טכנולוגיה
- React + TypeScript + Vite, אנימציות עם framer-motion.
- Supabase: טבלת `poker_players` (הדירוג) ופונקציות `poker_save_player` / `poker_record_match`. חדרי ראש בראש עובדים על Supabase Realtime (broadcast + presence).
- Capacitor: עוטף את המשחק לאפליקציה לאייפון (`ios/`) ולאנדרואיד (`android/`).

## הרצה מקומית
```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # בונה את dist/
```
משתני סביבה (לא חובה, יש ברירות מחדל) נמצאים ב-`.env.example`.

## העלאה לאינטרנט (Vercel)
מחברים את הריפו ל-Vercel. ההגדרות כבר קיימות ב-`vercel.json`. אחרי שיש כתובת, מגדירים אותה ב-Vercel כ-`VITE_PUBLIC_URL`, כדי שקישורי ההזמנה בוואטסאפ יצביעו עליה.

## העלאה לחנויות
**חשבונות שצריך:** Apple Developer (‏99$ לשנה) ו-Google Play Console (‏25$ חד-פעמי).

לפני ההעלאה הראשונה, משנים את `appId` ב-`capacitor.config.ts` (כרגע `com.pokeriq.app`) למזהה ייחודי משלך.

```bash
npm run build && npx cap sync      # מעתיק את המשחק לפרויקטים של iOS ו-Android
```

- **Android:** פותחים את `android/` ב-Android Studio ← Build ← Generate Signed Bundle ← מעלים את ה-‎.aab ל-Play Console.
- **iOS עם Mac:** מריצים `npx cap open ios`, ב-Xcode בוחרים Team ← Product ← Archive ← מעלים ל-App Store Connect.
- **iOS בלי Mac:** שירות ענן כמו Codemagic בונה ומעלה מהריפו (צריך לחבר את חשבון ה-Apple Developer).

**מדיניות החנויות:** משחקי פוקר בלי כסף אמיתי מותרים, אבל מסווגים כ"הימורים מדומים". באפל הדירוג יהיה כנראה ‎17+‎, ובגוגל צריך לסמן את זה בשאלון התוכן. אסור להוסיף אפשרות לזכות או לקנות כסף אמיתי.
